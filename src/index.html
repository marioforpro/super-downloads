Quick Guide

Quality: 1080p and 720p are usually fastest — the app takes an H.264 stream directly. Best goes up to 4K; when the source only offers 4K as VP9/AV1 (YouTube) it is converted to H.264 for editing, which takes longer.

Format: Audio MP3 saves only an .mp3 file — no video. It switches back to Video each time the app opens.

Auto add from clipboard: copied video links start downloading automatically. Off each time the app opens.
